# تشغيل TQM easy على GitHub Pages مع قاعدة بيانات أونلاين (Supabase)

**الفكرة:** الواجهة تعمل من رابط GitHub Pages، والبيانات في قاعدة Supabase المجانية، ودالة صغيرة اسمها `qmt` تفحص الدخول والصلاحيات. لا تحتاجين أي سيرفر. الإعداد حوالي 15 دقيقة، مرة واحدة.

## أولًا: Supabase (القاعدة والدالة)
1. ادخلي supabase.com واضغطي **Start your project**، وسجّلي بحساب GitHub. ثم **New project**: اكتبي اسمًا مثل `tqm-easy`، واختاري كلمة سر للقاعدة (احفظيها)، وأقرب منطقة لك، وانتظري دقيقتين حتى يجهز.
2. من القائمة الجانبية: **SQL Editor** ← **New query**. افتحي `supabase/setup.sql` والصقي محتواه كله ← **Run**. يجب أن تظهر رسالة نجاح.
3. **New query** جديد: افتحي `supabase/data.sql` (موجود في الملف الخاص `tqm-easy-PRIVATE-data.zip`) والصقي محتواه ← **Run**. هذا يحمّل مستخدميك وبرامجك و156 ملاحظة وسجل التدقيق كاملة.
4. من القائمة: **Edge Functions** ← **Deploy a new function** (أو **Via Editor**). اكتبي الاسم **qmt** بالضبط. امسحي الكود الموجود والصقي محتوى `supabase/functions/qmt/index.ts` ← **Deploy**.
   - في إعدادات الدالة، إن وجدتِ خيارًا اسمه **Verify JWT** أو **Enforce JWT Verification** فأوقفيه (الدالة تتحقق من الدخول بنفسها).
5. من **Project Settings** ← **API**: انسخي **Project URL** (يشبه `https://abcd1234.supabase.co`) و**anon public key** (مفتاح طويل يبدأ غالبًا بـ `eyJ`).

## ثانيًا: GitHub
6. في مستودعك `TQM-Easy` اضغطي **Add file** ← **Upload files**، واسحبي **كل محتويات** هذا المجلد (لا ترفعي الملف الخاص `PRIVATE-data`). اضغطي **Commit changes**.
7. افتحي الملف `config.js` في GitHub واضغطي القلم (Edit)، واستبدلي القيم الثلاث:
   - `api`: `https://<مشروعك>.supabase.co/functions/v1/qmt`
   - `url`: `https://<مشروعك>.supabase.co`
   - `anon`: مفتاح anon الذي نسختِه. ثم **Commit changes**.
8. انتظري دقيقة أو دقيقتين ثم افتحي `https://ayeshashadi5-sudo.github.io/TQM-Easy/` وادخلي بالاسم وكلمة السر.

## لو ظهرت مشكلة
| العَرَض | الحل |
|---|---|
| "Failed to fetch" أو لا يحدث شيء عند الدخول | تأكدي أن اسم الدالة `qmt` بالضبط، وأن `api` في `config.js` صحيح وينتهي بـ `/qmt` |
| خطأ 401 أو Invalid JWT | أوقفي **Verify JWT** للدالة، أو تأكدي من نسخ مفتاح anon كاملًا |
| "الاسم أو كلمة السر غير صحيحة" مع بيانات صحيحة | لم يُشغَّل `data.sql` بنجاح، أعيدي الخطوة 3 |
| الصفحة لا تتغير بعد التعديل | انتظري دقيقتين ثم أعيدي التحميل بقوة (Ctrl+F5) |
| ملف `data.sql` كبير على المحرر | قسّميه عند كلمة `insert into` وشغّلي الأجزاء بالترتيب بين `begin;` و`commit;` |

## ما يجب أن تعرفيه
- **المستودع عام** (لأن Pages المجاني يتطلب ذلك)، لكن لا أسرار فيه: الكود فقط. البيانات وكلمات السر في Supabase فقط، ومحمية خلف الدالة. لا ترفعي `data.sql` أو `current.json` أبدًا.
- مفتاح anon عام بطبيعته ولا يعطي وصولًا لأي بيانات. وصفحة الدخول مرئية لمن يعرف الرابط، والدخول يحتاج اسمًا وكلمة سر، مع إيقاف 10 دقائق بعد 5 محاولات خاطئة.
- كلمات السر 4 أرقام ومخزنة كنص ليراها الأدمن. غيّريها بعد أول دخول.
- المشاريع المجانية في Supabase قد تتوقف تلقائيًا بعد فترة بلا استخدام، فتُستأنف من لوحتهم بضغطة.
- التحديث بين المستخدمين كل 6 ثوانٍ تقريبًا.
- أي ملاحظة أُضيفت على نسخة Claude بعد تاريخ التصدير لن تكون هنا. أخبريني عند الانتقال الفعلي لأعيد التصدير.
